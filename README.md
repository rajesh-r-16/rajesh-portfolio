## `05` — RUN IT LOCALLY

Want to explore the source code or customize the interface?

### Prerequisites

- Node.js 18 or newer
- npm
- Git (optional, for cloning)

### Clone the repository

```bash
git clone https://github.com/rajesh-r-16/rajesh-portfolio.git
cd rajesh-portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, normally `http://localhost:5173`.

### Create a production build

```bash
npm run build
npm run preview
```

The production-ready files are generated in the `dist/` directory.

The portfolio is deployed on Vercel.

https://rajesh-portfolio-iota-roan.vercel.app/

To deploy your own changes:

1. Push the latest code to GitHub.
2. Import the repository into Vercel.
3. Set the build command to `npm run build`.
4. Set the output directory to `dist`.
5. Deploy and verify the generated URL.
